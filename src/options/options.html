Is my key safe here?

Short version: your key stays on this computer, kept the same way Chrome keeps your saved passwords. It is never uploaded to your Google account, never shown to YouTube, and never sent to us — there is no us, there is no server. The only thing that leaves is the transcript, and only to the provider you chose.

One tip worth following: make a key just for this extension and put a spending limit on it. Then if it ever leaks, you cancel that one key and nothing else is affected.

The precise version, for anyone who wants it

Your key is kept in chrome.storage.local, unencrypted. Anyone with access to your Chrome profile directory can read it — the same way they could read the passwords Chrome has saved for you. Encrypting it here would mean storing the passphrase next to the ciphertext, which protects nobody, so this extension does not pretend to.

It is never written to chrome.storage.sync, so it is never uploaded to your Google account or copied to your other machines.

The key is read only by the extension's background service worker, which is where every provider request is made. It is never handed to the YouTube page or the content script, so scripts running on youtube.com cannot see it.

The only outbound requests this extension makes are to the provider you configured above. There is no server of ours, no analytics, and no telemetry of any kind.

What gets sent to that provider, each time you summarize: the video's title, channel, duration, chapter titles, and the text of its captions. Once sent, that data is governed by your provider's data-retention policy, not by anything this extension does.
